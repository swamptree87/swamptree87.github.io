How the conversion works

A skybox is a function of the view direction. An equirectangular panorama stores that function as a 2:1 image where the horizontal axis is the compass heading (longitude) and the vertical axis is the angle from straight up (latitude). A cubemap stores the same function as six square images, each the view through one face of a cube centred on the camera. Converting between them means, for every pixel of the output, working out which 3D direction it shows and reading the colour of that direction from the input. This page does exactly that, with bilinear filtering, in JavaScript on your own machine.

Unity's manual defines the six slots by world axis, and its Left slot is the +X face, which sits to the right of a default camera. The files made here are named after the slot they go into, so put each file into the slot with the same name and the sky is upright with no swapped sides. The six images are "inside view" faces in the OpenGL cubemap layout: the bottom edge of Up meets the top edge of Front, as on an unfolded cross. The centre of the panorama becomes the Front face.

These are the same conventions our own packs use, and they were checked in Unity 6: faces line up with no seams, the horizon is level and the sky is upright. If your source panorama has a different "front" (the sun where you do not want it), rotate the panorama first by rolling it horizontally; a quarter of the image width is a 90 degree turn.

Import settings that avoid seams

  • Unity, six faces: Texture Shape 2D, sRGB on, Wrap Mode Clamp, Generate Mip Maps off, Filter Bilinear, Compression None or High Quality. Then a material with shader Skybox/6 Sided, each file in its slot; assign it in Window → Rendering → Lighting → Environment. The full walkthrough is in the Unity skybox guide.
  • Unity, one panorama: use the copy from step 2, Wrap Mode Repeat, Mip Maps off, shader Skybox/Panoramic, Mapping Latitude Longitude, 360 Degrees.
  • Godot 4: you do not need the cube faces at all. Put the panorama in a PanoramaSkyMaterial inside a Sky, inside an Environment, on a WorldEnvironment node. Steps and fixes are in the Godot 4 skybox guide. If you have only six faces, use step 3 here to make the panorama.
  • Face size: for a 4096 x 2048 panorama, 1024 px faces keep roughly the same detail per degree; 2048 px faces are sharper near the cube corners but four times the memory. Browsers can run out of memory above 2048.

Privacy and limits

No upload happens: the files are read by your browser and never sent anywhere. Very large images (8K panoramas, 4K faces) may be slow or fail in the browser; for batch work, our packs' pipeline does the same conversion offline. The output is 8-bit PNG, so an HDR source loses its range; convert HDR files in your engine or in Blender instead.
